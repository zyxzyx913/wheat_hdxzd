# 中国小麦外部数据集审计报告

审计范围：公开数据源、官方数据卡、官方仓库/发行页和现有项目近重复候选。没有修改 EWS、CGIAR、FoMo4Wheat、V1.1 评分或历史实验结果。

## 1. 先给出结论

本轮找到两个最值得继续推进的数据源：

1. **WheatPheno（南京农业大学，中国江苏）**：固定 PhenoCam 对同一批小区连续拍摄，两年、约 32 万张质量图像、五个生育阶段。它最适合建立“同一地块/小区当前图像 → 未来阶段或阶段间隔”的 RGB 外部验证样本，但公开页面没有说明最终产量和完整气象字段，Zenodo 页面也没有显示明确许可，下载后必须先核对 README 和数据使用条款。[PhenoNet 数据说明](https://phenonet.org/wheatpheno)、[Zenodo 数据记录](https://zenodo.org/records/8115362)
2. **GSP-AI/WGSP**：包含中国、英国和美国试验图像、气象因素、人工生育期和花期信息；官方 Release V1.1 提供模型、iPython 调用流程、环境因素表、CN 数据和 Smartphone 数据分卷。论文报告了生育期识别和开花日期预测，但测试数据标明为学术使用，不能直接当作商业接口权重。[官方 GitHub 仓库](https://github.com/The-Zhou-Lab/GSP-AI)、[官方 Release V1.1](https://github.com/The-Zhou-Lab/GSP-AI/releases)、[论文数据可用性说明](https://spj.science.org/doi/10.34133/plantphenomics.0255)

本轮没有下载大文件。尝试下载 GSP-AI 的小型环境因素表时，当前 Windows 沙箱网络被本地代理端口拒绝；没有留下不完整文件，也没有把“可访问页面”描述成“已下载”。

### 2.1 WheatPheno 的适配性

PhenoNet 页面明确说明：数据来自南京农业大学白马试验站；240 个 RGB 相机持续监测冬小麦，覆盖 2021 和 2022 两年；每台相机监测 4 个小区，每小时采集；公开摘要统计约 32 万张质量图像、5 个阶段、品种和氮水平信息。[PhenoNet 官方页面](https://phenonet.org/wheatpheno)

这满足未来预测最关键的“同一小区 + 图像时间序列”条件。仍需下载后核对：

- 图像文件名是否保留 camera/plot/date；
- 是否存在同一小区的完整日期序列；
- 质量图像是否经过时间抽样或增强；
- 五阶段标签是人工标签、规则标签还是后处理标签；
- 是否存在株高、覆盖率、叶面积、生物量或产量字段；
- Zenodo/README 的再分发和商业使用限制。

Zenodo 记录显示 Part1 压缩包约 8.9 GB，项目当前没有本地副本。不能在没有核对字段前宣称可以直接生成 7、15、30 天训练标签。

### 2.2 GSP-AI/WGSP 的适配性

GSP-AI 官方仓库说明包含 WGSP 数据、人工花期数据、环境数据和无人机关键生育期数据；官方 Release V1.1 提供 9.4 MB 模型包、iPython 调用文件、CN-UK-US 环境因素表、约 1.9 GB 分卷的 WGSP-CN 数据以及约 2.5 GB 分卷的 WGSP-Smartphone 数据。[官方 README](https://github.com/The-Zhou-Lab/GSP-AI/blob/main/README.md)、[官方 Release V1.1](https://github.com/The-Zhou-Lab/GSP-AI/releases)

论文摘要报告数据包括 70,410 张标注图像，来自中国 54 个品种、英国 109 个品种和美国 100 个品种；模型同时利用图像和多季气象数据，并报告开花日期 RMSE。论文还报告用中国手机图像进行测试，但这不等于对当前用户手机照片的验证。[论文页面](https://spj.science.org/doi/10.34133/plantphenomics.0255)

适配边界：

- 可作为中国生育期/花期预测基准和外部对照；
- 需要解压并核对 plot、日期、品种、环境和图像的真实键；
- 现有系统的 FoMo4Wheat 单图 768 维特征不能直接替代 GSP-AI 的图像+气象输入；
- Release 明确说明测试数据、软件和人工花期数据仅供学术使用，不能直接用于商业发布；
- 它预测花期日期和关键阶段，不是已经验证的未来 7/15/30 天覆盖率、株高或产量模型。

### 2.3 中国六种粮棉油发育期图像数据集

官方论文说明数据来自全国 642 个国家级农业气象观测站；从 2,891 张高质量图片中遴选出 668 张最终代表图像，其中小麦 100 张。图片为 JPG，文件名包含拍摄地点，经过两批专家鉴定和抽样复查。[官方数据论文 PDF](https://www.sciengine.com/cfs/files/pdfs/view/2096-2223/05E57EE6077C49BBB7E402497B9ADA22.pdf)

它适合作为中国发育期外部测试和人工标注参考，不包含同一地块的连续日期、未来表型值或天气序列，因此不能支持未来 7/15/30 天预测。

### 2.4 产量路线的中国数据

公开的中国低氮小麦数据集包含 210 个品种、2022 和 2023 两年、五个生育时期的 UAV 多光谱图像/植被指数，以及收获期产量和生物量；相同 ID 表示生物学重复，归档文件约 593 MB。[Zenodo 数据记录](https://zenodo.org/records/20500495)

它属于“同一试验对象多时期 + 产量”的 D 类候选，但输入不是普通 RGB，不能直接支撑当前网页的手机单图产量预测。可用于后续多光谱产量路线的标签和时间窗口设计。

## 3. 数据类型分类

### A. 只有单张图片或非纵向图像

- 中国六种粮棉油发育期图像：小麦最终 100 张，专家阶段标签，无未来目标。
- WGSW165：北京平台 3,778 张 PNG，公开描述强调第 165 天图像，未确认同一小区连续序列。
- CUWT：双视角手机图像和穗部性状，主要覆盖开花到早期灌浆，不是未来时间序列。

### B. 有多种时间/地点信息但当前公开摘要不能确认可匹配

- Kaifeng 2024 原始多光谱 UAV：时间覆盖 2024-01-04 至 2024-06-30，但发布版本说明未提供正射图或明确 plot 级键，需结合代码和文件结构核验。[Zenodo 数据记录](https://zenodo.org/records/18778904)
- GSP-AI/WGSP 的完整 plot/date 键需要解压 Release 分卷后确认，不能只根据论文摘要构造样本。

### C. 同一地块/小区连续观测

- WheatPheno：固定相机、固定小区、小时级采集，两年；当前最适合 RGB 未来阶段变化准备。
- GSP-AI/WGSP：试验图像和人工生育期/花期数据具备时序建模基础，但需要解包核对唯一键。
- FIP1：瑞士 plot 级连续图像和表型日期，作为方法开发对照，不是中国外部数据。

### D. 同一对象连续观测并有产量

- 中国低氮小麦 UAV 数据：五阶段多光谱/VI + 产量/生物量，适合多光谱产量模型。
- FIP1：RGB 图像序列 + canopy/height/spike/senescence/yield，适合作为未来窗口和产量任务的结构参考。

当前没有找到同时满足“中国、普通 RGB、同一地块多时相、未来表型值、最终产量、天气完整公开”的单一数据集。需要组合 WheatPheno/GSP-AI 的 RGB 时间序列与独立产量数据，或通过合作获取同一试验的产量表。

## 4. 当前项目兼容性

- WheatPheno 和中国六种粮棉油数据均可复用现有 Pillow 图像读取、ExG/HSV/Otsu/Fusion 分割和 FoMo4Wheat 768 维特征提取器。
- GSP-AI 的原始模型使用较旧的 TensorFlow/Jupyter 依赖，官方 README 列出 TensorFlow 2.2、scikit-image 0.17 等版本；建议隔离环境运行，不要升级现有 `.venv`。[官方 README](https://github.com/The-Zhou-Lab/GSP-AI/blob/main/README.md)
- 多光谱 UAV 数据不能直接送入当前 RGB 算法；需要单独记录波段、辐射校准和 ROI 处理。
- Windows 11 可以保存和预处理上述文件，但 8.9 GB、数 GB 分卷和 593 MB 压缩包需要预留空间，并应先读取目录/元数据再批量解压。

本轮尝试下载 GSP-AI 小型环境因素表，受到当前沙箱网络代理限制而失败；没有下载大文件或留下损坏数据。项目新增的来源清单见 `data/processed/china_wheat_external/source_manifest.csv`。

## 5. 未来 7/15/30 天数据准备建议

### 5.1 首选任务定义

第一阶段不要直接预测“长势好坏”或最终价格。建议先做可测量的连续目标：

```text
输入：plot_id、当前图像 I(t0)、拍摄日期 t0、可选品种/氮水平/天气历史
目标：同一 plot 在 t0+7、t0+15、t0+30 附近的阶段标签或图像指标
```

WheatPheno 最适合先构造“未来阶段/距离下一阶段天数”；FIP1 可用于 canopy cover、height、spike count 等连续目标的窗口规则验证；中国低氮数据用于后续产量/生物量路线。

### 5.2 严格配对规则

对每个 `plot_id`：

1. 按真实日期排序图像，不跨地块、年份或环境匹配；
2. 只匹配未来日期，禁止把同日或过去观测当作未来目标；
3. 7 天候选容差预设 ±2 天，15 天 ±3 天，30 天 ±5 天；
4. 保存实际间隔天数和偏差，不把 12 天样本标成严格 15 天；
5. 缺失目标保持缺失，不做线性外推填补；
6. 同一 plot 的所有日期只能进入一个数据集合；
7. 按 plot、年份、试验环境做 Group split，不能按图片随机拆分。

### 5.3 评价指标

- 阶段/事件：Accuracy、Macro-F1、每阶段 Recall、时间误差 MAE；
- 连续目标：MAE、RMSE、R²、MAPE（目标非零且适用时）；
- 外部泛化：按年份、地点、品种和手机/无人机设备分别报告；
- 低置信度：保留拒判比例、覆盖率和误差，不把拒判样本删除后再报成绩。

## 6. 推荐顺序

1. **先申请/下载 WheatPheno Part1 的元数据和小规模样本**：先核对 plot/camera/date/label 字段，再决定是否下载 8.9 GB 全包。
2. **再获取 GSP-AI/WGSP Release 的 CN 和 Smartphone 分卷**：优先读取目录和环境因素表，建立中国阶段/花期外部验证清单；模型在独立环境中运行。
3. **最后处理中国低氮多光谱产量数据**：为未来产量路线建立阶段→产量/生物量标签，暂不接入普通 RGB 网页。

## 8. 交付结论

- 找到中国 RGB 多时相首选：WheatPheno。
- 找到中国生育期/花期预测首选：GSP-AI/WGSP。
- 找到中国专家阶段外部测试集：六种粮棉油发育期图像数据集。
- 找到中国多时相产量路线候选：中国低氮小麦 UAV 多光谱数据。
- 当前没有可直接证明支持“中国手机单图 → 未来 7/15/30 天连续长势/产量”的公开单一数据集。
- 在连续观测数据真正下载、字段配对和分组验证完成前，不训练未来预测模型，不在网页显示预测曲线。
