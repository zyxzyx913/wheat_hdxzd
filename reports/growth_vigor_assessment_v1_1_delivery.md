# 小麦长势智能评价 V1.1 交付报告

## 1. 交付范围

本次在现有长势分析 V1 的真实图像指标基础上，新增可解释的“表观长势初评”规则。输入仍然是用户上传的一张 RGB 图片和实际运行得到的植被掩膜；没有修改 ExG、HSV、Otsu-ExG、ExG-HSV Fusion 算法，也没有把 EWS 二分类标签当成长势标签。

评价版本：`growth-vigor-v1.1-rule`

这不是深度学习模型，不是经过农学试验校准的标准，也不等同于叶绿素、氮含量、植株密度、生育期或未来趋势预测。

## 2. 实际评分公式

先将三个 V1 图像指标分别转换为 0～100 的标准化分数，再按权重计算综合分：

```text
vigor_score = 0.45 × coverage_score
            + 0.35 × greenness_score
            + 0.20 × uniformity_score
```

当前可追溯配置：

| 评分项 | 标准化规则 | 权重 |
|---|---|---:|
| 植被覆盖 | `clip(覆盖率 / 0.75 × 100, 0, 100)` | 0.45 |
| 绿色程度 | `clip(前景区域平均 G/255 × 100, 0, 100)` | 0.35 |
| 空间均匀度 | `clip((1 - CV / 1.5) × 100, 0, 100)` | 0.20 |

覆盖率参考值 `0.75` 和均匀度 CV 上限 `1.5` 是可配置的演示参数，并非农学验证阈值。每次 API 响应会保存标准化分数、权重、贡献值和配置。

等级规则明确为初步演示规则：

- 80～100：长势较好
- 60～79：长势一般
- 0～59：长势较弱

## 3. 图像质量和可靠性

图像质量不直接进入长势分数，只用于可靠性检查。继续复用 V1 的平均亮度、过暗比例、过曝比例、饱和比例、拉普拉斯方差和风险提示。

- 检测到没有植被前景：不输出等级。
- 画面偏暗或过曝：不输出等级，并提示重新拍摄。
- 清晰度参考值偏低：降低可靠性；单独出现时保留分数但提示复查。
- 无风险：可靠性为“较高”；有非阻断风险为“中等”；阻断风险为“较低”。

因此 `vigor_score` 可能存在，但 `vigor_level` 可以为 `null`。这避免把低质量图像强行包装成等级结论。

## 4. API 返回

原有 `POST /api/image/analyze` 保持不变，并在响应中增加：

- `vigor_score`
- `vigor_level`
- `coverage_score`
- `greenness_score`
- `uniformity_score`
- `reliability`
- `strengths`
- `improvement_suggestions`
- `evaluation_version`

完整评分依据同时位于 `growth_analysis.vigor_assessment`，原始 V1 指标继续保留。

## 5. 网页功能

长势分析页新增：

- 综合评分和等级卡片所需的数据接口。
- 覆盖、绿色程度、均匀度三个可解释评分数据。
- 可靠性、优势和改善建议数据接口。
- 已同步的图像识别任务可以直接用于长势初评。

当前页面保留既有深色麦田背景、磨砂玻璃面板、原图/掩膜/叠加图、覆盖率环形图、均匀度热力图和图像质量卡片。前端构建通过。

## 6. 测试结果

- 长势指标与规则测试：10 passed。
- 全部单元测试：135 passed，3 skipped，4 subtests passed。
- FastAPI 接口测试：42 passed。

测试使用的程序生成图像仅用于验证公式、边界和错误处理，不代表真实小麦实验成绩。

## 7. 当前边界

1. 当前规则没有经过专家长势标签校准，不能宣传为真实农学诊断。
2. 不同生育期的合理覆盖率和绿色程度不同，当前尚未使用生育期校正。
3. 单幅 RGB 图像受拍摄角度、遮挡、光照、背景和分割算法影响，不能代表真实田间密度或生物量。
4. 当前等级不预测未来 7/15/30 天长势，不预测产量和价格。
5. CGIAR/EWS 标签没有提供长势好坏真值，不能据此计算长势等级准确率。

## 8. 下一步农学验证

应收集同一地块、同一时期的 RGB 图片与专家长势等级，按地块和年份环境划分训练/验证/测试集；再用这些标签校准覆盖率、绿色程度、均匀度的参考范围和等级阈值，并报告独立测试集的 Macro-F1、混淆矩阵和置信区间。在完成校准前，网页必须继续显示“表观长势初评/等待专家标签校准”。
