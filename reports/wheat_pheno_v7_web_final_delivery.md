# 麦视通 V7.0 全站网页优化与最终交付报告

## 1. 全站审计结果

已检查 `frontend/src/views`、`components`、`router`、`services`、`package.json` 和后端 API 路由。当前主要页面包括首页、图像识别、长势分析、市场与收益、我的报告、科研标注，以及生长预测/产量预测/科研中心等预留页面。

已确认：

- 路由映射完整，未知路径回到首页。
- 图像识别、长势分析、市场与收益、我的报告均有真实页面和 API 调用。
- 空数据区域使用明确空状态，不生成示例成绩。
- GSP-AI、未来定量预测和价格预测在数据不足时保持不可用。
- 历史报告删除只作用于 Web 分析任务目录，不触碰 EWS、CGIAR、模型权重和历史实验结果。
- 现有功能建设中页面保留为研究预留，不伪装为已完成业务。

## 2. 本轮完成的优化

### 首页

- 快捷入口状态由统一模块配置驱动。
- 已接入的图像识别、长势分析、市场与报告状态不再统一显示为“功能建设中”。
- 顶部状态改为“分析服务已接入 · 结果以真实数据为准”。
- 保留动态麦田品牌视觉和真实数据边界说明。

### 长势分析页

- 保留图片上传、四种分割算法、V1.1 评分、生育期识别、天气情景和农事建议。
- 保留低置信度提示、预测不可用提示、历史记录和地块编号追踪。
- 维持深绿色麦田背景、磨砂玻璃和响应式布局。

### 市场与收益页

- 保留真实全国小麦价格历史展示。
- 增加最高价、最低价、数据截止日期和近期方向状态。
- 保留 30 天预测和收获期情景的不可用边界。
- 收益计算器支持种植面积、预计亩产、总成本、总产量、收入和利润。

### 报告页

- 保留历史记录列表、详情、原图/叠加图、评分、生育期、指标、地块历史和 JSON 导出。
- 删除操作保留确认提示和分析目录范围保护。

## 3. 数据真实性

当前正式全国小麦价格仍只有一条：2026-11-10，2417 元/吨。网页不会绘制虚假历史曲线，也不会在历史不足时生成 30 天或收获期价格预测。

未来长势模块继续区分：当前图像诊断、天气风险筛查、情景分析和未验证的定量预测。GSP-AI、WOFOST/PCSE 和未来定量生长预测没有被误显示为已完成。

## 6. 尚未解决的问题

1. 当前本机网络仍阻塞真实 Open-Meteo HTTP 请求，天气页面会如实显示不可用状态。
2. 全国小麦历史价格仍只有 1 条真实记录，价格预测和回测未启用。
3. 生育期模型来自 CGIAR，低置信度和中国域迁移限制仍需人工复核。
4. 未来定量生长预测没有经过真实田间验证。
