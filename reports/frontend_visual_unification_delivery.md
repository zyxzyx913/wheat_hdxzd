# 麦视通全站视觉统一交付报告

## 视觉基准

以现有图像识别工作台的深色农业驾驶舱为基准，统一使用深森林绿背景、嫩绿色强调、真实农业场景暗化背景、深色玻璃面板、细绿色描边和一致的状态标签。

## 修改内容

- 新增 `frontend/src/styles/ui-unification.css`：集中统一页面容器、玻璃卡片、表单控件、状态标签、焦点和悬停视觉。
- 在 `frontend/src/main.js` 引入统一样式。
- `GrowthPrediction.vue`：保留7/15天规则预测，改为图像识别页同款的左侧预测条件区 + 中央趋势/KPI/结果区驾驶舱布局。
- `YieldPrediction.vue`：统一标题、历史记录卡、参数卡、产量情景卡和收益摘要卡。
- `MarketReturns.vue`：通过共享样式统一市场卡片、价格列表、输入控件和空状态。
- `Reports.vue`：通过共享样式统一报告列表、详情卡、状态和按钮。
- `GrowthAnalysis.vue`：保留原有图像分析、生育期、评分、天气和农事建议功能，并由共享样式统一卡片与控件基线。
- 图像识别页保持为视觉基准，未改动其业务组件。

## 功能保护

保留图像上传、四种分割算法、长势评分、生育期识别、7/15天预测、天气风险、农事建议、产量情景、收益估算、历史报告查询和删除等功能；未修改后端接口语义。

## 验证结果

- `npm run build`：通过，Vite 成功构建。
- 相关 Python 测试：`6 passed`。
- 统一样式包含深色输入/下拉控件、焦点状态、玻璃卡片、响应式栅格和窄屏单列规则。
- 未执行自动化浏览器截图验收；启动开发服务器后建议检查 1920×1080、1366×768 和手机宽度。
